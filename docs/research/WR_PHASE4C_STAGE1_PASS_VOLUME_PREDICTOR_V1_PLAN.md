## Historical script source and temporal contract

Reuse the already-reviewed PR #558 historical semantics rather than inventing new play/pass definitions:

- `plays_est` = realized team offensive plays in the historical team-week source used by PR #558.
- `dropback_rate` = realized team dropback/pass-rate quantity used by PR #558.
- nflverse schedules provide home/away/rest and the reviewed spread/total sign convention.

Seasons:

- **2021**: history-only backstop for strictly-prior rolling features. Never a model label row.
- **2022**: initial script-model training season.
- **2023**: downstream A/B/C fit season; its script feature must itself be generated by a model trained only on 2022.
- **2024**: fully blind Stage-1 downstream test season; its script feature must be generated by a model trained only on 2022+2023.

For every target team-game, all rolling football features must use rows with chronological ordinal strictly less than the target game. Target-game or future PBP is forbidden. Cross-season history is allowed only in the forward direction.

## Frozen realized-pass-volume target

Define the historical script target at team-game grain as:

`realized_pass_volume = plays_est * dropback_rate`

This is a compact realized pass-volume state, not a WR outcome and not a market label.

No alternate target (final margin, actual total, target count, confirmation label, WR targets, receiving yards) may replace or rescue it after output.

## Frozen football-only script features

For each target team-game construct exactly these six pregame features:

1. `team_plays_prior8` — mean own `plays_est` over prior 8 games.
2. `team_dropback_rate_prior8` — mean own `dropback_rate` over prior 8 games.
3. `opp_plays_allowed_prior8` — mean offensive `plays_est` produced by opponents faced by the target opponent's defense over its prior 8 games.
4. `opp_dropback_rate_allowed_prior8` — mean offensive `dropback_rate` faced by the target opponent's defense over its prior 8 games.
5. `home_flag` — 1 home, 0 away.
6. `rest_diff` — target-team rest days minus opponent rest days from the pregame schedule.

Rolling window = 8, minimum prior games = 3. If either team lacks the minimum history, that target row is unavailable; do not impute it from target-season outcomes.

No market variable enters the script submodel. This is intentional: Arm B already owns the market information, so `C > B` has a clean interpretation that football-derived script prediction adds something beyond the market.

No PROE feature is introduced in V1 because this repo does not have a separately frozen historical PROE definition authorized for this experiment; adding one after output would constitute a new feature-family test.

## Frozen script model

One model family only:

`StandardScaler -> Ridge(alpha=20.0)`

No hyperparameter search, alternate learner, nonlinear interaction search, thresholding, feature selection, or target transform.

Two forward fits generate the script feature:

- **2023 prediction**: fit on eligible 2022 label rows only; freeze; predict eligible 2023 team-games.
- **2024 prediction**: fit on eligible 2022+2023 label rows only; freeze; predict eligible 2024 team-games.

The emitted scalar is `pred_realized_pass_volume`.

For basic predictor-health reporting only, compare it with the naive strictly-prior product:

`naive_pass_volume = team_plays_prior8 * team_dropback_rate_prior8`.

## Frozen downstream A/B/C comparison

The downstream target is the canonical Phase-4B team target-pool residual:

`r = actual_team_targets - implied_team_target_pool`.

Fit all residual models on the same eligible **2023** Phase-4B team-games, freeze coefficients, and score the same eligible **2024** Phase-4B team-games.

All continuous training features are centered using 2023 training means only; those frozen means are applied to 2024.

### A — calibrated football authority baseline

Intercept-only residual model:

`r ~ 1`

Prediction:

`pool_A = implied_team_target_pool + predicted_residual_A`.

The uncalibrated authority `implied_team_target_pool` is reported separately as `A0`, but A is the fair fitted comparator so B/C do not get free credit merely for fitting an intercept.

### B — authority + frozen Gate-0 market environment

`r ~ 1 + market_total + low_total_lt38`

where `low_total_lt38 = 1[market_total < 38]` uses the already-frozen PR #559 bucket edge.

No spread, moneyline, `market_team_implied`, alternate total threshold, spline, polynomial, or interaction is allowed in the decisive B arm. This intentionally leans on the two load-bearing Gate-0 findings Claude independently endorsed.

### C — B + our predicted realized pass-volume state

`r ~ 1 + market_total + low_total_lt38 + pred_realized_pass_volume`

Same model family and 2023 fit cohort as B. The only added information is the football-only, strictly pregame OOS script scalar.

No post-output coefficient clipping or hand blending.

## Blind-2024 metrics

On eligible 2024 Phase-4B team-games, report for A0/A/B/C:

- team-target MAE
- team-target RMSE
- signed bias (`prediction - actual`)
- paired rowwise absolute-error differences for B-vs-A, C-vs-B, and C-vs-A.

Bootstrap paired differences with **10,000 reps, seed 20260915**, clustering by actual NFL game so opposing team rows remain together. The schedule game identifier is joined before resampling.

## Prospective Stage-1 go/stop rule

Disposition is `QUALIFIED_PREDICTED_PASS_VOLUME_INCREMENT` **only if every condition below passes**:

1. **Coverage/integrity**
   - >=95% of the 515 canonical 2024 Layer-2 team-games receive a valid `pred_realized_pass_volume`;
   - >=95% of the 222 primary-tail team-games receive it;
   - zero target/future-game rows enter any script feature;
   - 2024 outcomes never enter script fitting or A/B/C fitting.

2. **Script predictor has real blind skill**
   - on eligible 2024 team-games, `pred_realized_pass_volume` MAE is strictly lower than `naive_pass_volume` MAE;
   - paired game-cluster bootstrap 95% CI for `abs_error_naive - abs_error_script` has lower bound > 0.

3. **Decisive incremental test: C > B**
   - 2024 team-target MAE improvement `MAE_B - MAE_C >= 0.10` targets/team-game;
   - paired game-cluster bootstrap 95% CI lower bound > 0.

4. **C is useful relative to the football baseline too**
   - `MAE_A - MAE_C >= 0.10` targets/team-game;
   - paired game-cluster bootstrap 95% CI lower bound > 0.

5. **No hidden tail-cost tradeoff**
   - `RMSE_C <= RMSE_B`;
   - `abs(bias_C) <= abs(bias_B) + 0.25` targets/team-game.

6. **WR-room translation is positive**
   - `WR-room MAE_B - WR-room MAE_C > 0` on blind 2024;
   - paired game-cluster bootstrap 95% CI lower bound > 0.

7. **Tail mechanism alignment**
   - C reduces mean absolute team-target error vs B on the 222 primary opportunity-tail team-games;
   - at least one of the two frozen secondary tail definitions (87 actual-100+ opp-dominant or 312 full underprojection team-games) shows the same positive direction.
   - Tail CIs are reported but are not required to exclude zero because these are smaller diagnostic slices; they cannot rescue a failed full-cohort gate.

If **any** condition fails, disposition = `NO_ACTIONABLE_PREDICTED_PASS_VOLUME_INCREMENT`; close this Stage-1 lane. Do not try alternate alpha, model family, PROE definition, market threshold, spread feature, margin target, interaction, subgroup, or reverse rotation as a rescue.

B-vs-A market increment is reported transparently but is not itself the decisive gate; C must beat both B and A under the rules above.
