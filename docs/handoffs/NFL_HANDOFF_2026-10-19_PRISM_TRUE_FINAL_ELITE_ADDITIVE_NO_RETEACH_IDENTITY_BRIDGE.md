# 1. ABSOLUTE MODEL ASSIGNMENT

PRISM is an **INDIVIDUAL-PLAYER PROJECTION MODEL**.

The objective is:

> Project the named player correctly in his actual current football state for
> the exact market.

The model is not trying to create generic position rules and then push every
player through them.

Permanent rule:

> **THE PLAYER SHOULD HAVE THE RULES. THE POSITION SHOULD NOT HAVE THE PLAYER.**

Correct reasoning order:

`PLAYER IDENTITY / HISTORY
-> CURRENT ROLE / STATE
-> EXPLAIN ABNORMAL OBSERVATIONS
-> TEAMMATE COMPETITION / FINITE OPPORTUNITY
-> OPPORTUNITY TYPE / QUALITY
-> OPPONENT / ENVIRONMENT
-> EFFICIENCY
-> EXACT MARKET OUTCOME
-> RELIABILITY`

A mechanism is not scientifically useful unless we can answer:

> **WHY SHOULD THIS SPECIFIC PLAYER'S PROJECTION CHANGE?**

Position-level MAE/RMSE is **not the optimization objective**.

It is downstream QA/reporting only.

If named-player projections improve, aggregate position error should improve as
a consequence.

Do not:
- lead with position averages;
- optimize aggregate MAE and then invent player rules to force it down;
- treat a player mechanism as successful merely because an average moved;
- treat a position coefficient as player identity.
