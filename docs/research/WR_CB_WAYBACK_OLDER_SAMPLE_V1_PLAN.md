# Older WR-CB Wayback Availability Sample V1

Bounded metadata-only pilot to determine whether older FantasyAlarm WR/CB vintages are more recoverable than 2024.

Targets:
- 2022 W5, W12, W18;
- 2023 W5, W10, W15;
- 2024 W1 known-positive snapshot as mandatory endpoint control.

Publication times and exact URLs are taken from the already-preserved source-audit artifact; no current article reacquisition. The shared availability probe performs only three bounded archive-metadata lookups per article. No archived body, target outcomes, sportsbook data, editorial grade, or model fitting.

If older useful timestamps are found, verify at most the strongest candidates individually using the existing exact-body digest + per-WR kickoff + exact WR/opponent-CB weekly roster contract. A failed lookup is not evidence the snapshot never existed.
