# M90 Run Notes

Before launch, the confirmation runner must be checked against `scripts/backtest/run_m89_pregame_synthesis.py` on the M89 parent branch. The M90 candidate must use the exact M89 football-only feature contract, Ridge alpha 20.0, and ±45 yard residual cap. Any mismatch is a mechanical defect and must be corrected before interpreting M90 results.
