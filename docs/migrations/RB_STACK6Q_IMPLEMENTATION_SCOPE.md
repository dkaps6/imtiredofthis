# RB STACK6Q — Implementation Scope Clarification

## Status

Frozen before any 2025 STACK6Q scoring. This note does not change the 20-feature contract, Ridge alpha, clips, blend weight, gates, or dispositions in `RB_STACK6Q_DESIGNED_RUN_CALL_MODEL_PLAN.md`.

## 2024 training environment

The authoritative M94C artifact contains a leakage-safe `m94c_2024_holdout_trace.csv` for Weeks 13-18 and the untouched `m94c_2025_team_trace.csv` validation trace.

STACK6Q will therefore fit its three state-specific designed-run Ridge models only on eligible 2024 W13-18 target rows from the frozen M94C holdout trace. This is preferable to manufacturing full-season 2024 M94C environment predictions after the fact, because the holdout predictions were generated by the original M94C development protocol from earlier 2024 information.

For each state, rows with zero realized target-state offensive plays remain excluded from that state's training label, exactly as frozen in the plan.

## Strict-prior histories

The 20 predictors are built from 2023-2025 nflverse PBP using only games strictly before each target team-week. Opponent defensive allowed histories are keyed by the target opponent's prior defensive games. QB-designed-run environment uses the same QB identification semantics already present in `scripts/build/pbp_features.py`: passers establish the QB name universe; non-scramble, non-kneel rush attempts by those players count as designed QB runs.

Scramble and kneel nuisance rates remain unfitted prior-five-game team rates shrunk to strict-prior league state rates with 24 pseudo-plays.

## Frozen identities

Before interpretation, the run must verify:

- 544/544 2025 M94C team-games join to the frozen STACK6H trace;
- 388 W6-18 team-games;
- M94C candidate total-rush values reproduce the STACK6H `T_hat` values to numerical tolerance;
- reconstructed PBP rush attempts reproduce the M94C PBP truth bridge to numerical tolerance;
- every constructed predictor is strict-prior by construction;
- no sportsbook field or target-week participation/injury field is present.

The seven scientific qualification gates are unchanged and no gate may be waived.
