# QB-WR Shared Pass-Volume Mechanism Audit

## Status

`PREREGISTERED / CROSS-POSITION DIAGNOSTIC ONLY`

## Prior result

The frozen QB-WR residual-coupling audit found strong same-team same-game error coupling across 884 2024-2025 team-games:

- all-WR receiving-yard residual vs QB passing-yard residual Pearson `0.728638`
- Spearman `0.701332`
- same-sign rate `0.656109`
- high-vs-low WR-error quartile QB residual gap `125.972` yards
- positive and stable in both 2024 and 2025

That establishes shared error structure, but not a pregame causal mechanism. Some relationship is mechanically expected because QB passing yards are produced by receivers.

This audit tests the narrower football hypothesis that a meaningful portion of the coupling is generated by a *shared passing-volume miss*.

## Position independence

This is a separate bridge lane. It may not alter the independent QB or WR model merely because a postgame relationship is found.

QB and WR research continue independently. Any later cross-position integration must use only pregame information and must pass a separate full-stack test.

## Primary mechanism test — 2025 target mass

For each 2025 team-game:

- QB attempt residual = `actual_attempts - pred_attempts`
- WR target-mass residual = sum across all WRs of `actual_targets - pred_targets`

The primary question is whether teams for which the QB model under/overpredicts pass attempts also systematically have under/overpredicted aggregate WR target opportunity.

Frozen primary metrics:

- aligned team-games
- Pearson correlation
- Spearman correlation
- same-sign rate excluding exact zeros
- mean QB attempt residual in top quartile minus bottom quartile of WR target-mass residual
- W2-18 correlation
- W13-18 correlation

Frozen strong-mechanism gate — all must pass:

1. aligned 2025 rows >= `400`
2. Pearson >= `0.50`
3. Spearman >= `0.45`
4. same-sign rate >= `0.65`
5. top-minus-bottom quartile QB attempt-residual gap >= `5.0` attempts
6. W2-18 Pearson > `0`
7. W13-18 Pearson > `0`

Disposition if all pass: `STRONG_SHARED_PASS_VOLUME_MECHANISM`.
Otherwise: `NO_STRONG_SHARED_PASS_VOLUME_MECHANISM`.

Thresholds may not be lowered after results.

## Secondary replication — 2024-2025 WR receptions

Because exact reconstructed M38 target opportunity is currently canonical for the 2025 ND5 cohort, use aggregate WR reception residual as a broader secondary replication on 2024-2025:

- aggregate WR reception residual = sum(`actual_receptions - projected_receptions`)
- compare against QB attempt residual
- report combined and season-specific Pearson/Spearman/same-sign/quartile-gap metrics

This secondary test is descriptive and cannot rescue a failed primary target-mass gate.

## Interpretation

A pass means the existing independent QB and WR models are frequently making a common error in the volume environment. It would authorize a later frozen experiment in which a shared *pregame latent pass-volume state* feeds QB attempts and team target mass jointly inside Monte Carlo.

It would not authorize using realized WR targets/receptions as QB inputs or realized QB attempts as WR inputs.

A fail means the strong QB-WR yardage residual relationship is more likely dominated by efficiency, allocation, or the mechanical accounting identity of passing/receiving yards rather than a recoverable shared volume state.
