## 1. Why this audit exists

PRISM is an individual-player projection model.

Canonical football order:

`PLAYER IDENTITY -> CURRENT ROLE/STATE -> TEAMMATE COMPETITION -> OPPORTUNITY ALLOCATION -> OPPORTUNITY QUALITY -> OPPONENT/ENVIRONMENT -> EFFICIENCY -> RELIABILITY -> MARKET-SPECIFIC OUTCOME`.

The Week-5 named-player forensic replay found that the same named player can move
between opportunity-dominant, efficiency-dominant and mixed failure states from
one week to the next.

That result means the unresolved object is not a permanent player correction.

The unresolved question is:

> Given this named player's historical identity/playbook and the football state
> available before kickoff, which role regime is active **now**, and how much
> authority should that current regime receive for the exact market being
> projected?

This audit determines whether that question is genuinely open after reconciling
the project's already-tested player-state families.

It scores no candidate.

## 11. What is genuinely missing

After anti-retest reconciliation, the project has evidence for:
- whether the player participates;
- important forms of finite opportunity allocation;
- WR/TE recent target-share direction;
- an RB carry/snap state shadow;
- named-player projection reliability;
- stable player-specific efficiency states;
- partial opponent/team context.

What remains incompletely represented is **state arbitration across horizons**:

> When the named player's current football state differs materially from his
> longer identity/baseline, is that difference a true role transition that
> should carry more authority for this market, or short-term noise that should
> remain shrunk toward the player's stable identity?

This is not equivalent to recent share.

A legitimate state-arbitration object would need independent football evidence
of a regime transition, such as source-qualified combinations of:
- starter/depth-role transition;
- sustained participation/snap transition;
- room composition / teammate competition change;
- current-season role trajectory already represented where qualified;
- team/QB/coaching context change where historical/live parity exists;
- market-specific opportunity-type transition.

The evidence must be available strictly before the target game.

## 12. Market specificity is mandatory

A state change cannot be assumed to affect every prop the same way.

Examples:

### RB carries
State evidence should affect:
- participation;
- carry-room ownership;
- short-yardage / early-down role where supported.

### RB rushing yards
Carry state is upstream, followed by:
- individual rushing efficiency;
- valid run environment;
- player-conditioned opponent obstacle;
- reliability.

### WR/TE targets
Existing target-share trajectory and entitlement science remain protected.

### Receiving yards
Target state alone is insufficient:
- target count;
- target type/depth where supported;
- player efficiency;
- opponent interaction;
- reliability all matter.

### Touchdowns
A yards-state transition is not automatically a touchdown-state transition.
TD logic requires scoring-area / high-value opportunity ownership and team
scoring access.

This preserves the Dobbins-style lesson embedded in the PRISM architecture.
