## Purpose

Test whether the independently successful TE-R5 team-pool + participation-entitlement mechanism remains beneficial when embedded in the same finite team passing ecosystem as QB, WR, RB and the residual receiver bucket.

This is intentionally a **joint-system confirmation and an independent position test at the same time**.

The hypothesis is:

> A leakage-safe TE team target-pool estimate plus participation-aware within-room entitlement can improve individual TE opportunity and receiving-yard projections **without creating net damage to WR/RB receiving projections or QB passing-yard distributions when all receiving opportunity is conserved inside one shared team pass state.**

TE-R6 may not create extra team pass opportunity. Any increase in modeled TE target mass must come from the finite modeled non-TE receiver mass. The residual receiver mass remains explicit and unchanged.

## Frozen TE individual entitlement model

Use the exact TE-R5 model and rules without modification:

No hand corrections, player overrides or post-result tuning.

## Frozen finite-opportunity transform

For each team-game after the exact C2 baseline target probabilities are created:

1. Let `M` = sum of all baseline modeled pass-catcher target probabilities included in C2 before the residual receiver bucket.
2. Let `T0` = sum of baseline TE target probabilities.
3. Let `N0 = M - T0` = baseline modeled non-TE probability mass.
4. Let `A` = the exact pregame C2 expected team pass attempts used for expected-target translation.
5. Compute raw TE candidate probability mass `T_raw = candidate_te_pool / max(A, 1e-12)`.
6. Set `T1 = clip(T_raw, 0, M)` **only as a finite-pool feasibility bound**. Report every bound hit; no alternate cap is allowed.
7. Set `N1 = M - T1`.
8. Allocate `T1` across TEs using the exact TE-R5 softmax room shares.
9. If `N0 > 0`, multiply every baseline non-TE modeled receiver probability by the single factor `N1/N0`. This preserves all within-non-TE relative shares exactly.
10. If `N0 == 0`, require `N1 == 0`; otherwise disposition is mechanical/integrity failure.
11. Residual receiver probability remains exactly `1 - M`, identical to B0_C2.

Therefore for every team-game:
- modeled receiver probability mass is exactly conserved;
- residual receiver mass is exactly conserved;
- any TE opportunity gain is paid for by modeled non-TE opportunity loss and vice versa;
- M38 WR relative hierarchy is preserved;
- RB/FB relative receiving ordering is preserved;
- no extra team passing opportunity is manufactured.
