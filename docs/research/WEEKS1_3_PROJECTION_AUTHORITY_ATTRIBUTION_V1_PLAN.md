# Weeks 1-3 Projection Authority Attribution V1 — Frozen Plan

Status: FROZEN BEFORE RESULTS  
Date: 2026-09-29  
Branch: `research-week3-postmortem-execution-v1`

## Purpose

Use the already-settled canonical 2026 Weeks 1-3 selected betting record to identify
where current-production projection error is present or introduced across the
stored projection authorities.

This is a diagnostic-only current-production audit. It does not fit a correction,
change a model weight, retune a threshold, or authorize a production rule.

## Frozen input

Authority is the canonical cumulative Weeks 1-3 graded row set generated by
`Weeks1-3 Postmortem Diagnostics V1`, with:
- frozen publication/eligibility gates;
- verified player identity aliases;
- Week-3 Bagent nonparticipation settlement evidence;
- zero unresolved settlement rows.

Only rows with `settlement_status == SETTLED` and finite actuals are eligible for
projection-error comparisons. VOID rows are excluded from projection accuracy.

## Frozen questions

1. **Base MC -> final**
   - Compare `mc_proj` with `model_proj` on identical rows.
   - Report MAE, RMSE, signed bias, and paired absolute-error improvement
     `abs(mc_proj-actual) - abs(model_proj-actual)`.
   - Positive paired improvement means the final model improved on MC.

2. **Ensemble -> final**
   - Compare `ensemble_proj` with `model_proj` on identical rows where both
     are finite.
   - Same paired metrics.

3. **Component / specialist presence**
   On rows where the stored application flag is true, report final-model error
   separately for:
   - `ml_applied`
   - `state_applied`
   - `qb_synthesis_applied`
   - `rb_synthesis_applied`
   - `qb_distribution_specialist_applied`
   - `rb_receiving_tail_applied`
   - `rb_r26_receptions_applied`
   - `rb_rush_rec_conservation_v2_applied`
   - `discrete_count_alignment_applied`

   This is descriptive only. A flag cohort is not a causal estimate.

4. **Final movement direction**
   - For each row, compute `model_proj - mc_proj`.
   - Determine whether that movement moved toward or away from the realized
     actual.
   - Summarize by week, position, market, and direction of movement.

5. **Persistent low-bias localization**
   - Determine whether the cumulative negative final-model bias already exists
     in `mc_proj`, is reduced by the final model, or is amplified by the final
     model.
   - Give special visibility to RB `rush_rec_yards`, but do not create an
     RB-only rescue rule.

## Statistical boundary

Primary outputs are paired descriptive diagnostics on identical rows.
No category is promotable from this audit.

Optional paired uncertainty:
- game-cluster bootstrap confidence interval for mean paired absolute-error
  improvement, 10,000 deterministic replicates;
- no multiple category promotion gate is defined because this audit does not
  select a production winner.

## Anti-reinvention rules

Do not:
- reopen generic distribution widening;

- fit Week-3-only offsets;
- add a QB/pass-yards carveout;
- add a side rule;
- retune RB mean formulas;

- change any production code.
