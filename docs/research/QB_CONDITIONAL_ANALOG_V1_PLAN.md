# QB Conditional Historical-Analog Reliability V1 — Frozen Plan

## Status

Frozen before any 2025 outcome is opened. No fitting has occurred. No
production path is touched by this document. This plan is the direct
successor to `QB_CONDITIONAL_ANALOG_V1_ANTI_RETEST_AUDIT.md`, which
classified the core construct `GENUINELY_OPEN` with an explicit strong
negative prior (three of four closest precedents in this program failed on
honest holdout or preregistered gates).

Market: QB `pass_yards` only. No other market or position is in scope for
V1.

## 2. Feature definitions (four dimensions, all pregame-observable)

All columns below are read unchanged from `m89_2024_2025_synthesis_trace.csv`
(i.e. from `FOOTBALL_FEATURES`/`MARKET_FEATURES` in
`run_m89_pregame_synthesis.py`). No new feature is computed for V1; only
existing, already-frozen pregame columns are selected and standardized.

1. **Model-internal disagreement** (reused frozen from QB-PD3, per the
   audit's explicit carve-out — continuous distance contribution, not a
   binary reliability gate): `component_sd`, `component_range`,
   `pred_attempts`, `pred_ypa`.
2. **Player strict-prior attempt/YPA**: `qb_prior_attempts`, `qb_prior_ypa`.
3. **Opponent strict-prior pass-defense efficiency**: `def_pass_epa_allowed`,
   `def_success_allowed`, `def_ypa_allowed`, `def_pass_rate_faced`.
4. **Market-implied game script**: `market_total`, `market_spread`,
   `market_abs_spread`, `market_team_implied`, `market_opp_implied`,
   `market_is_underdog`, `market_moneyline`.

Fifteen columns total, equally weighted (see distance metric below — no
per-dimension weighting is fit or tuned for V1).

## 3. Missingness policy

**Exclude, never impute.** Any row (in either the 2024 reference pool or
the 2025 evaluation pool) with a null value in any of the 15 frozen feature
columns is dropped from the analog population entirely before distances are
computed. `run_m89_pregame_synthesis.py` imputes internally for its own
regression fit; that imputation is not reused here, because imputing a
missing pregame value would fabricate a point in similarity space rather
than honestly narrowing the population — consistent with this repo's
existing discipline of never fabricating missing inputs (e.g. the Sharp
Football coverage-outage tolerance work). Rows dropped for missingness are
counted and reported, not silently discarded.

## 4. Scaler

`sklearn.preprocessing.StandardScaler`, fit once on the 2024 reference pool
only (post-missingness-exclusion), frozen, and applied unchanged (transform
only, no refit) to every 2025 evaluation row. This mirrors the fit-2024/
freeze/evaluate-2025 discipline already used by
`diagnose_market_implied_game_script_v1.py` and the QB-PD3/M89 lineage.

## 5. Distance metric

One frozen metric only, no metric shopping: **Euclidean distance in the
standardized 15-dimension feature space** described above. No Mahalanobis,
cosine, or learned-weighting alternative is evaluated for V1.

## 6. Neighbor rule, sample size, and quality gate

- **k = 15 nearest neighbors**, fixed, no k-sweep.
- **Neighbor pool is season-scoped**: for a 2025 evaluation row, eligible
  neighbors are 2024 reference-pool rows only (never same-season or future
  rows) — a genuine "look up historically comparable pregame states and see
  what happened" design, not a same-season leak.
- **Quality/density gate, derived from feature-space coverage only (no
  outcome or ROI data touched to set it):** compute each 2024 reference row's
  own leave-one-out k-NN distance (k=15) against the rest of the 2024 pool.
  Take the 90th percentile of that in-pool distribution as the frozen
  density threshold. For any row (2024 in-sample or 2025 evaluation), if its
  distance to its own k-th nearest neighbor exceeds that frozen 90th-
  percentile threshold, the row is `NO_ANALOG_SUPPORT` — its neighborhood is
  too sparse to trust, and no lower-quality neighbor set is substituted.

## 7. Evidence classes (row-level, only assigned if the architecture-level
gate in Section 8 passes)

- `SUPPORTED`: density gate passes AND the row's k-NN analog set shows a
  directional edge that clears the architecture-level 2025 gate (Section 8).
- `DESCRIPTIVE_ONLY`: density gate passes but the analog set's directional
  edge does not clear the gate (context only, no selection signal).
- `NO_ANALOG_SUPPORT`: density gate fails (row's pregame state has no
  adequate 2024 historical analog neighborhood).
- `NO_HISTORICAL_TRUST_SCORE`: row is outside V1 scope (any market/position
  other than QB `pass_yards`) — mirrors the existing `Bet Evidence V0`
  convention (`scripts/bet_evidence_v0_overlay.py::classify_v0`) so the two
  overlays stay visually consistent if ever shown together.

These are descriptive annotation labels only, matching the Bet Evidence V0
contract: they never modify projection, probability, EV, signal, eligibility,
or `Decision`.

## 8. Architecture-level 2025 blind confirmation — hard pass/fail gate

This is evaluated exactly once, after Sections 1-6 are implemented and
frozen without inspecting any 2025 outcome.

For each 2024 reference row, label it by the realized direction/ROI of its
own market bet (the same side/probability-edge convention the authority-
exact Vegas benchmark already records) against its `k=15` analog neighbors'
own realized ROI — i.e., does the analog-implied direction match what
actually happened, in-sample, on 2024. This defines the `SUPPORTED` vs
`DESCRIPTIVE_ONLY` split rule purely from 2024, before 2025 is opened.

Apply that frozen, un-retuned rule to the 2025 evaluation pool. The
architecture passes (`QB_CONDITIONAL_ANALOG_RELIABILITY_SUPPORTED`) only if
**all** of the following hold on the 2025 `SUPPORTED` bucket:

- N >= 40 rows (density-gate-passing, rule-flagged `SUPPORTED`) in 2025.
- ROI in the 2025 `SUPPORTED` bucket is positive.
- ROI in the 2025 `SUPPORTED` bucket exceeds the unconditional 2025 QB
  `pass_yards` ROI baseline (over the full 771-row-derived 2025 population)
  by a positive margin — i.e. the analog signal must add something beyond
  the market's own baseline directional tendency, not just inherit it.
- Directionally consistent with the 2024 in-sample split (2024 `SUPPORTED`
  bucket ROI also positive — expected in-sample, but checked and reported).

There is exactly one preregistered test (one k, one metric, one threshold,
one evidence rule). No multiple-comparisons correction is applied because
none is needed: the "no metric/k/threshold shopping" constraint itself is
the correction, matching the discipline already used by QB-PD3 and
Migration 88.

If **any** gate fails: disposition
`NO_ACTIONABLE_QB_CONDITIONAL_ANALOG_RELIABILITY`. The architecture is
closed outright. No nearby-k, nearby-metric, nearby-distance-threshold, or
nearby-feature rescue — identical discipline to QB-R1, QB-PD3, and
Migration 88, all of which closed on first honest holdout rather than being
retuned.

## 9. 2026 transport rule (only if Section 8 passes)

If and only if the 2025 blind confirmation passes: 2024+2025 combined
become the frozen reference/analog library for 2026. The scaler is refit
once on the pooled 2024+2025 reference pool (both seasons are now historical
relative to 2026); `k=15`, the Euclidean metric, and the 90th-percentile
density threshold (recomputed on the pooled reference pool via the same
leave-one-out procedure in Section 6, not re-tuned against any outcome) carry
forward unchanged. No retuning of k, metric, or thresholds using 2025
results is authorized under any circumstance.

## 10. No-production-mutation statement

Whether Section 8 passes or fails, this architecture — even if
`SUPPORTED` — is a downstream, descriptive research overlay only, in the
same category as `Bet Evidence V0` (PR #618). It does not, by itself,
authorize any change to `project_game_script()`, `rules_v2.py`,
`simulation_rules.py`, projections, probabilities, EV, Snapshot Signal,
eligibility, or `Decision`. Production integration, if ever proposed, is a
separate, explicitly authorized future step requiring its own review.
